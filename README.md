# ✍️ AI Writing Studio

個人用の AI ライティングツール。ブログ記事の執筆・メール文面の作成・文章の要約を、
1 つのブラウザ画面にまとめています。

技術スタックは **Python + Streamlit + Gemini API**。データベースもログイン機能もない、
ローカルで動かすだけのシンプルな構成です。

---

## できること

| タブ | 内容 |
| --- | --- |
| **ブログ記事** | テーマ・想定読者・トーン・文字数を指定して Markdown の記事を生成 |
| **メール文面** | 用件と要点からビジネスメールを作成。返信元を貼れば返信メールも作れる |
| **文章要約** | 貼り付けた文章を「3行まとめ／箇条書き／段落／議事録風」で要約 |

生成中の文章はリアルタイムで流れてきます（ストリーミング表示）。
できあがった文章はプレビュー・コピー用テキスト・Markdown ダウンロードの 3 通りで受け取れます。

## セットアップ

### 1. API キーを取得する

[Google AI Studio](https://aistudio.google.com/apikey) で Gemini API のキーを発行します。

### 2. `.env` を作る

```bash
cp .env.example .env
```

`.env` を開いて、発行したキーを記入してください。

```
GEMINI_API_KEY=AIza...
```

> `.env` は `.gitignore` に入っているので、Git にコミットされることはありません。

### 3. 依存パッケージをインストールする

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

---

## 起動する

```bash
source .venv/bin/activate
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。
止めるときはターミナルで `Ctrl + C`。

## 使い方のコツ

- **サイドバーの「モデル」** — 迷ったら既定の `Gemini 3.6 Flash` のままで十分です。
  品質を上げたいときは `3.7 Flash`、下書きを量産したいときは `3.5 Flash Lite`。
- **サイドバーの「考える深さ」** — 定型的なメールなら `minimal`、
  構成を練ってほしいブログ記事なら `medium` 以上が向いています。深くするほど時間はかかります。
- **「さらに細かく指定する」を開く** — 見出し案やその他の指示を書くほど、狙った文章に近づきます。
- **要約は原文に忠実** — 原文にない情報を足さないよう指示しています。
  原文で結論が出ていない話は「結論は出ていない」と書かれます。

## ファイル構成

```
.
├── app.py              # Streamlit の画面（UI）
├── writer/
│   ├── config.py       # モデル一覧と既定値
│   ├── gemini.py       # Gemini API 呼び出し（ストリーミング）
│   └── prompts.py      # 3 機能のプロンプト組み立て
├── requirements.txt
├── .env.example
└── README.md
```

機能を追加したいときは `writer/prompts.py` に組み立て関数を 1 つ足し、
`app.py` にタブを 1 つ増やす、という流れになります。
使えるモデルを増やしたいときは `writer/config.py` の `MODELS` に 1 行足すだけです。

## 注意

- 生成結果はどこにも保存されません。残したいものはダウンロードしてください。
- API の利用料金は Google のアカウントに課金されます。無料枠と料金は
  [Gemini API の料金ページ](https://ai.google.dev/gemini-api/docs/pricing) を確認してください。
- AI の出力は必ず自分の目で確認してから使ってください。特に日時・金額・固有名詞は要確認です。
  （メール生成では、こちらが伝えていない情報は `【要確認: ○○】` と明示されます）
